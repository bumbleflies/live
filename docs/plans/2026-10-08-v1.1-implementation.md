# live v1.1 (persistent room + embedded VDO windows) Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Room links survive restarts and rotations only happen explicitly; guests can join their streaming window directly on the site.

**Architecture:** Room state moves from an in-memory map to a single JSON file under `DATA_DIR` (volume-backed in prod). `POST /api/room` becomes idempotent; `POST /api/room/rotate` is the only mutation. The SPA embeds the four publish-window iframes and gains a confirm modal for rotate.

**Tech Stack:** Express 5, vitest/supertest, React 19 (no new deps).
